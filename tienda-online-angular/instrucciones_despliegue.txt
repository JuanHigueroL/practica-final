GUÍA DE DESPLIEGUE Y PRUEBA DE LA APLICACIÓN (VERSIÓN ANGULAR)

Sigue estos pasos en el orden indicado para poner en marcha la aplicación (Backend, Frontend y Base de Datos).

1. REQUISITOS PREVIOS
   - Tener instalado Node.js (versión 16 o superior).
   - Tener instalado y en ejecución MySQL Server.
   - (Opcional) Angular CLI instalado globalmente.

2. CONFIGURACIÓN DE LA BASE DE DATOS (MySQL)
   - Abrir el gestor de bases de datos (MySQL Workbench o similar).
   - Crear una nueva base de datos.
   - Ejecutar el script SQL proporcionado en los archivos para crear automáticamente las tablas y la estructura necesaria.
   - Verificar en el archivo de configuración del backend que las credenciales (usuario y contraseña de MySQL) coinciden con las de la instalación local.

3. DESPLIEGUE DEL BACKEND (Servidor)
   - Abrir una terminal en la carpeta 'backend'.
   - Ejecutar el comando: npm install
     (Esto instalará todas las dependencias necesarias: Express, MySQL2, Multer, Cors, etc.)
   - Una vez finalizada la instalación, iniciar el servidor con: node index.js
   - El servidor estará escuchando en http://localhost:3000. No cerrar esta terminal.

4. DESPLIEGUE DEL FRONTEND (Interfaz Angular)
   - Abrir una nueva terminal en la carpeta del proyecto Angular (ej. 'tienda-angular').
   - Ejecutar el comando: npm install
     (Esto instalará el core de Angular, RxJS y el resto de dependencias).
   - Una vez finalizada la instalación, compilar e iniciar la aplicación con: npm start (o 'ng serve' si se dispone de Angular CLI).
   - La aplicación se abrirá automáticamente o estará disponible en el navegador en: http://localhost:4200.

5. NOTAS PARA LA PRUEBA
   - La tienda cargará los productos y categorías iniciales conectándose a la base de datos a través del servicio central de Angular.
   - Para añadir, editar o eliminar productos y categorías, acceder al botón "Panel Admin" situado en la barra de navegación. 
   - El acceso al entorno de administración requerirá la introducción de una clave de acceso básica configurada para esta prueba: 123456
   - Al añadir productos que contengan imágenes, estas se enviarán empaquetadas (FormData) y se guardarán físicamente en la carpeta de subidas (uploads) del backend.
